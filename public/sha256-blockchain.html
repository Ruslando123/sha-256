// WHY DOES THIS MATTER?

🔍
What is a nonce? A number miners change to get a different hash output. It has no other meaning — it's just a guess counter.
🎯
Why leading zeros? Bitcoin requires hashes to start with many zeros. Only ~1 in 16 hashes starts with one zero — so it takes real work.
⚡
What is "difficulty"? The number of leading zeros required. Each extra zero makes mining ~16× harder on average.
🏦
Why can't miners cheat? SHA-256 is a one-way function. There's no shortcut — you must try random nonces until one works.

// REAL WORLD · BITCOIN 2024

Bitcoin currently requires hashes to begin with approximately 19–20 leading zeros in hexadecimal. That means the valid hash space is roughly 1 in 10²³ — smaller than the number of atoms in a gram of carbon.

This is why the entire Bitcoin network, running trillions of hashes per second, still takes ~10 minutes to find one valid block.
